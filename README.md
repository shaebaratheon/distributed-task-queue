# Distributed Task Queue in Go

A fast, lightweight, priority-driven concurrent in-memory task distribution system.

## Key Features
- High-concurrency worker pools with graceful worker shutdown
- Task exponential backoff retries and status state machine
- Strict priority queue ordering (Critical, High, Normal, Low)
- Context-bound timeouts and cancellation propagation
